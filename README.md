## ماذا وجدنا في ملف Query_fixed-1.apk؟

- **سبب عدم عمل الملف:** هو الجزء الأساسي فقط من حزمة Google Play المقسّمة (Split APK). ينقصه ملف المكتبات الأصلية (lib/…)، لذلك لا يُثبَّت أو يتوقف فور فتحه. الملف نفسه يعلن داخلياً أنه يحتاج أجزاء أخرى.
- **التطبيق مبني بنسخة قديمة جداً من React Native،** ويعتمد على خادم قديم `api.querry-app.com` عبر http غير المشفّر، وهذا غير مقبول اليوم في المتاجر.
- **مفتاح Google Maps مكشوف داخل التطبيق** (يبدأ بـ `AIzaSyBr3K8`). إن كان المفتاح لك، ألغه أو قيّده من Google Cloud Console فوراً.

لذلك أُعيد بناء التطبيق من الصفر بنفس فكرته ووظائفه، مع خادم جديد وتصميم جديد.

## الحماية من المحتوى الممنوع (جديد)
- **فلتر تلقائي في الخادم** يرفض قبل الحفظ أي سؤال أو إجابة أو تصويت أو اسم أو نبذة فيها:
  - محتوى إباحي أو خادش للحياء.
  - إساءة للأديان أو المقدسات.

  يعمل بالعربية والإنجليزية والتركية والإسبانية، ويكشف التحايل مثل التشكيل، ومدّ الحروف، وفصلها بمسافات، واستبدالها بأرقام.
- **اختبار الدقة:** يمنع 29 مثالاً مخالفاً، ولا يمنع 33 سؤالاً عادياً، منها أسئلة دينية وطبية.
- **الكلمات في ملف واحد:** `backend/src/lib/moderation.js`، ويمكن إضافة كلمات إليه دون تعديل أي شيء آخر.
- **فحص اختياري للصور والفيديو** عبر Sightengine.
- **بلاغات «إباحي» أو «إساءة للأديان»:** تُخفي المحتوى من بلاغين، وتنبّه المشرفين فوراً.
- **العقوبات:**
  - المشرف يحذف المحتوى ويستطيع إيقاف صاحبه.
  - يُوقف الحساب تلقائياً 30 يوماً بعد 3 مخالفات.
  - الحساب الموقوف لا يستطيع الدخول أو النشر.

- **سياسة خصوصية كاملة:** البيانات التي نجمعها، وكيف نستخدمها، وما يراه الآخرون، والمشاركة، والحذف، والأطفال، والتواصل.

## أفكار جديدة أُضيفت
- **أفضل إجابة:** صاحب السؤال يختار أفضل إجابة، فتُثبَّت في الأعلى ويصل صاحبها إشعار.
- **نوع سؤال جديد «تصويت»:** من 2 إلى 4 خيارات، مع نسب مئوية وإمكانية تغيير الصوت.
- **السؤال دون إظهار الاسم:** للأسئلة الحساسة مثل الصحة والأسرة. يمكن حظر صاحب السؤال المجهول دون كشف هويته.
- **الإبلاغ عن المحتوى:** يُخفى المحتوى تلقائياً بعد عدة بلاغات، مع لوحة مراجعة للمشرفين. هذا شرط من Google Play وApp Store لأي تطبيق يسمح للمستخدمين بالنشر.
- **أسئلة قريبة:** خريطة للأسئلة عن الأماكن من حولك.
- **صندوق إشعارات داخل التطبيق** مع عدّاد، بالإضافة إلى الإشعارات الفورية.
- **ترتيب الأسئلة:** الأحدث، والأكثر تفاعلاً، وبلا إجابة، مع البحث.
- **إحصائيات الملف الشخصي:** عدد الأسئلة والإجابات وأفضل الإجابات، وصفحة عامة لكل مستخدم.

- **اختيار الأقسام بعد التسجيل** مباشرة، حتى لا تكون الصفحة الرئيسية فارغة.

## 1) الخادم (backend) — بدون أي مكتبات خارجية

- **المتطلبات:** Node.js 22.5 أو أحدث. الخادم يستخدم قاعدة بيانات SQLite المدمجة في Node نفسه.
- **لا يحتاج `npm install`.**

```bash
cd backend
cp .env.example .env      # غيّر JWT_SECRET
npm run seed              # (اختياري) بيانات تجريبية: demo@query.app / demo1234
npm start                 # http://localhost:4000
npm test                  # 16 اختباراً شاملاً تشغّل الخادم الحقيقي
```

**النشر:**
- يوجد ملف `Dockerfile`. يمكن النشر على أي استضافة تدعم Node أو Docker (Railway، Render، Fly.io، VPS).
- **مهم:** اجعل مجلد `data/` (قاعدة البيانات) ومجلد `uploads/` (الصور والفيديو والصوت) على قرص دائم.
- ضع `PUBLIC_URL` برابط الخادم الحقيقي بصيغة https.
- ضع بريدك في `ADMIN_EMAILS` لتحصل على صلاحية مراجعة البلاغات.
- لإرسال رموز استعادة كلمة المرور بالبريد، أضف مفتاح Resend. بدونه تظهر الرموز في سجل الخادم فقط.

## 2) التطبيق (mobile) — Expo / React Native

```bash
cd mobile
npm install
npx expo install --fix    # يضبط إصدارات المكتبات على أحدث Expo SDK
npx expo start
```

- **رابط الخادم:**
  - الافتراضي `http://10.0.2.2:4000`، ويعمل مع محاكي أندرويد.
  - على هاتف حقيقي: `EXPO_PUBLIC_API_URL=http://عنوان-جهازك:4000 npx expo start`
- **الخرائط على أندرويد:** ضع مفتاح Google Maps جديداً في `app.json`.
- **الإشعارات الفورية:** نفّذ `eas init` مرة واحدة، ثم أضف مفتاح Firebase (FCM) لأندرويد.

**بناء ملف للتثبيت أو للمتجر:**
```bash
npm install -g eas-cli && eas login
# ضع رابط الخادم الحقيقي في eas.json
npm run build:apk     # APK للتجربة والتثبيت المباشر
npm run build:aab     # AAB للرفع على Google Play
```
