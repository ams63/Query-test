# دليل النشر خطوة بخطوة (Google Play و App Store)

كل ما يمكن تجهيزه مسبقاً موجود في المشروع. المتبقي حسابات وبيانات تخصك أنت، ولا يمكن لأحد إنشاؤها نيابة عنك.

## ما هو جاهز
- **الخادم:**
  - يعمل بدون أي مكتبات خارجية.
  - عليه 30 اختباراً آلياً، كلها ناجحة.
  - يمكن نشره بثلاث طرق: `render.yaml` للنشر بضغطة، أو `deploy/docker-compose.yml` لأي خادم خاص مع HTTPS تلقائي، أو `Dockerfile`.
- **صفحات الويب التي تشترطها المتاجر، يقدّمها الخادم نفسه بأربع لغات:**
  - سياسة الخصوصية: `https://نطاقك/privacy`
  - الشروط وقواعد المجتمع: `https://نطاقك/terms`
  - حذف الحساب من الويب: `https://نطاقك/delete-account` (شرط Google Play)
- **حماية المحتوى:**
  - فلتر تلقائي يمنع المحتوى الإباحي والخادش للحياء والإساءة للأديان بالعربية والإنجليزية والتركية والإسبانية.
  - بلاغات تُخفي المحتوى تلقائياً، ولوحة مشرف.
  - إيقاف الحسابات المخالفة، تلقائياً بعد 3 مخالفات.
- **الأيقونات:** أيقونة المتجر 1024×1024، وأيقونة أندرويد المتكيفة، وشاشة البداية، وأيقونة الإشعارات.
- **رسائل أذونات iOS** مترجمة لأربع لغات.
- **ملف `eas.json`** جاهز للبناء والرفع للمتجرين.
- **نصوص صفحة المتجر** بأربع لغات: `docs/STORE_LISTING.md`
- **الربط مع وسائل التواصل** (مشاركة، دخول بـ Apple وGoogle، صفحتك في فيسبوك وإنستغرام، الرسائل): `docs/SOCIAL.md`
- **إجابات نماذج الخصوصية وتصنيف المحتوى:** `docs/DATA_SAFETY.md`

## الخطوات

### 1) الخادم، حوالي 20 دقيقة
1. ارفع المشروع إلى GitHub.
2. في Render اختر New ثم Blueprint، واختر المستودع. سيقرأ `render.yaml` وينشئ الخادم مع قرص دائم.
3. املأ `PUBLIC_URL` (رابط الخدمة) و`ADMIN_EMAILS` (بريدك).
4. تأكد أن الصفحات تعمل: `/health` و`/privacy` و`/terms` و`/delete-account`.
5. سجّل حسابك من التطبيق ليكون حساب المشرف. إن لم يكن بريدك في `ADMIN_EMAILS`، نفّذ `npm run make-admin -- بريدك`.

### 2) التطبيق
1. في مجلد `mobile` نفّذ: `npm run setup`. يثبّت المكتبات ويضبط إصداراتها ويتحقق من اكتمال الترجمات.
2. ضع رابط الخادم مكان `https://YOUR-API-DOMAIN` في `eas.json`، وضع رابط الخصوصية في `app.json`.
3. ضع مفتاح Google Maps مكان `PUT_GOOGLE_MAPS_ANDROID_KEY_HERE` في `app.json`.
4. نفّذ `npx eas login` ثم `npx eas init` لربط المشروع.
5. الإشعارات على أندرويد: `npx eas credentials`، ثم ارفع مفتاح FCM من Firebase.
6. لبناء نسخة تجريبية للتثبيت المباشر: `npm run build:apk`.
7. للمتجر:
   - أندرويد: `npm run build:aab` ثم `npm run submit:android`
   - iOS: `npm run build:ios` ثم `npm run submit:ios`

### 3) صفحة المتجر
- انسخ النصوص من `docs/STORE_LISTING.md` لكل لغة.
- **لقطات الشاشة:** شغّل `node tools/store-screenshots.js <رابط المعاينة أو التطبيق>` على جهاز متصل بالإنترنت. ينتج مقاسات Google Play وApp Store.
- أجب نماذج «أمان البيانات» و«تصنيف المحتوى» من `docs/DATA_SAFETY.md`.
- ضع روابط الخصوصية وحذف الحساب من الخطوة 1.

### 4) قبل الضغط على «نشر»
- [ ] جرّب APK على هاتفين: تسجيل، سؤال بكل نوع، إجابة، إشعار، إبلاغ، حذف حساب.
- [ ] جرّب نشر كلمة ممنوعة وتأكد أنها تُرفض.
- [ ] راجع سياسة الخصوصية مع محامٍ (نظام حماية البيانات الشخصية في السعودية).
- [ ] فعّل النسخ الاحتياطي: `npm run backup` يومياً، أو لقطات القرص من الاستضافة.
- [ ] أبقِ حساب مشرف يراجع البلاغات يومياً، فالمتاجر تشترط الاستجابة للبلاغات.

## ملاحظات مهمة للمتاجر
- **تطبيقات المحتوى الذي ينشره المستخدمون تشترط أربعة أشياء، وكلها موجودة:** قواعد واضحة يوافق عليها المستخدم، وإبلاغ عن المحتوى، وحظر المستخدمين، ومراجعة وحذف سريع.
- **Apple قد تطلب حساباً تجريبياً للمراجِع:** أنشئ `review@نطاقك` وضع بياناته في App Store Connect.
- **يمكن تفعيل فحص الصور والفيديو تلقائياً** عبر Sightengine بإضافة المفتاحين في إعدادات الخادم. بدونه يعتمد التطبيق على فلتر النص والبلاغات.
